# Orbit — Space Quiz

Orbit is a responsive, browser-based space trivia quiz. Answer 10 multiple-choice questions, get immediate feedback and explanations, and see your score at the end. The app is self-contained in `index.html` and has no build step or runtime dependencies.

## Run locally

Open `index.html` directly in a modern web browser. No server or installation is required.

## Deploy

GitHub Actions publishes the repository root to GitHub Pages whenever a commit is pushed to `main`. You can also start a deployment from the **Deploy to GitHub Pages** workflow using **Run workflow**.
